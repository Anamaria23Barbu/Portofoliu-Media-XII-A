Test de verificare github
1. Ce este un depozit și ce conține el în plus față de un folder obișnuit de pe calculator?
 Un dosar pe GitHub, cu foldere și fișiere, care are o adresă proprie.
  
2. Ce este un commit? Ce informații înregistrează GitHub la fiecare commit?
  Fișierele adăugate sau modificate se înregistrează în depozit împreună cu o scurtă descriere, data, ora și autorul.

3. Care sunt regulile GitHub pentru parolă și pentru numele de utilizator?
Parola: trebuie să respecte cerințele de securitate ale GitHub și să fie suficient de puternică. Este recomandată o parolă unică, greu de ghicit.
Numele de utilizator: poate conține caractere alfanumerice și cratime (-), dar nu poate începe sau se termina cu o cratimă și nu poate conține două cratime consecutive.

4. Dintre numele de utilizator ana-ionescu, -ana-, ana ionescu și ana_ionescu, care sunt acceptate de GitHub? Se justifică răspunsul pentru fiecare.
ana-ionescu - Da - Cratima este permisă în interiorul numelui.
-ana- - Nu - Începe și se termină cu o cratimă.
ana ionescu - Nu- Conține un spațiu.
ana_ionescu - Nu - Caracterul _ nu este permis în numele de utilizator GitHub.

5. Ce se face pe calculatorul din laborator la sfârșitul orei și de ce?
Pe calculatorul din laborator, parola nu se salvează în browser, iar la sfârșitul orei se iese din cont: clic pe imaginea de profil (dreapta sus), apoi Sign out.

6. Prin ce diferă un depozit Public de unul Private? Care se alege pentru portofoliu și de ce?
Public: poate fi vizualizat de oricine.
Private: poate fi accesat doar de proprietar și de persoanele autorizate.
Pentru portofoliu se alege Public: numai așa se poate publica site-ul cu un cont gratuit.
